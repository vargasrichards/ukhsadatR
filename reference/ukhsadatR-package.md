# ukhsadatR: R Interface to Access UKHSA Dashboard Data

Programmatic interface to access data from the UK Health Security Agency
(UKHSA) Data Dashboard API, with bulk retrieval helpers for whole
sub-themes and for the UKHSA Fingertips 'AMR local indicators' profile.
The package was originally based on the 'ukcovid19' package by Pouria
Hadjibagheri and has been substantially rewritten and extended. For more
information on the API, see
<https://ukhsa-dashboard.data.gov.uk/access-our-data>.
